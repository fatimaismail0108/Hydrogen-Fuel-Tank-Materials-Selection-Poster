Materials Selection for Hydrogen Fuel Tank

This project demonstrates materials selection for a hydrogen fuel tank interior using Granta EduPack and materials indices.

Overview

Determined the optimal material for the tank interior by evaluating candidate materials against safety, durability, degradation resistance, sustainability, and cost constraints.

Selected carbon fibre composite as the best option based on performance and lifecycle considerations.

Assessed trade-offs using quantitative materials indices to balance engineering, environmental, and economic factors.

Presented findings via a technical poster illustrating the selection process and rationale.

Tools & Techniques

Granta EduPack – Materials database and indices

Materials indices methodology – Quantitative comparison of candidates

Lifecycle, safety, and sustainability assessment

Outcomes

Identification of a high-performance, sustainable material solution for hydrogen storage.

Clear demonstration of data-driven engineering decision-making for applied materials science.
